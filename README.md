# 🌐 Personal Web Page

## 📌 Project Overview  
This project is a simple personal web page created using basic HTML. It introduces the author, provides background information, and highlights educational interests and career goals in web design and development.

## 👩‍💻 Author  
**Josephine Olive Nyuma**  
- Program: BSEM

## 📖 About the Project  
This web page serves as a personal profile showcasing:

- A brief introduction  
- Educational background  
- Interest in web design and technology  
- Career aspirations  

It is designed to demonstrate fundamental HTML structure and content organization.

## 🎯 Features  
- Simple and clean layout  
- Structured sections (Header, Main, Footer)  
- Personal biography and goals  
- Easy-to-read format
